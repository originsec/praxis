# Introduction

Praxis is a framework for monitoring and managing AI agent sessions. It provides visibility into how AI coding assistants interact with your systems, capturing prompts, responses, and tool usage.

## Components

- **Node** - Agent that runs on target systems to monitor AI assistant activity
- **Service** - Central backend that aggregates data and manages configuration
- **Web** - Browser-based UI for viewing sessions and managing the system

## Features

- Real-time monitoring of AI agent sessions
- Support for multiple AI assistants (Claude Code, Gemini CLI, M365 Copilot)
- Session replay and analysis
- Centralized configuration management
- Atlas: Built-in AI assistant for querying monitored agents
